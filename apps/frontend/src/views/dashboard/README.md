# 航行情报动态信息看板 — 重构方案

## 概述

基于 `feat/aero-intel-dashboard` 分支的初版看板，进行全方位重构。废弃原有"概览-态势-明细-底座"四层垂直布局，改为**三栏 + 顶部固定栏**的专业运控中心布局，精确还原目标截图中的产品形态。

## 新布局结构

```
┌──────────────────────────────────────────────────────────────────┐
│  顶部全局状态栏（48px）                                          │
│  [页面标题]        [双周期生效时间]        [时间切换：今日/明日/两日] │
├──────────┬────────────────────────────────┬──────────────────────┤
│          │                                │                      │
│  左侧    │         中间核心地图区          │     右侧             │

```

## 分模块实施计划

### 第一优先级：全局布局重构（预估 1 天）

**目标**：搭建和截图完全一致的页面骨架。

- [ ] 废弃原 `AeroIntelDashboard.vue` 的四层垂直滚动布局
- [ ] 新建三栏布局：`grid-template-columns: 320px 1fr 360px`
- [ ] 顶部全局状态栏（48px）
  - [ ] 左侧：页面标题"航行情报动态信息看板"
  - [ ] 中间：双周期生效时间（格式：`250501周期生效时间：05月15日`）
  - [ ] 右侧：时间切换按钮组（今日 / 明日 / 两日，选中态 `#00d4ff` 高亮）
- [ ] 左侧模块折叠功能
  - [ ] 右上角展开/收起按钮，收起后仅显示 48px 图标栏

## 废弃内容清单

以下初版组件在目标截图中未出现，本重构分支不再使用（保留源文件以便后续扩展）：

| 组件 | 原用途 | 废弃原因 |
|------|--------|----------|
| `ThreatRadar.vue` | SVG 威胁雷达 | 截图中无，替换为右侧航班动态 |
| `SeverityRing.vue` | 告警等级占比环 | 截图中无，替换为地图悬浮统计卡 |
| `LiveAlertFeed.vue` | 实时告警滚屏列表 | 截图中无，替换为左侧时间轴 + 限制表格 |
| `AlertTimeline.vue` | 24H 柱状趋势图 | 截图中无 |
| `StatsStrip.vue` | 6 张 KPI 统计卡片 | 替换为地图顶部 3 张悬浮统计卡 |
| 底部系统状态底座 | 6 子系统状态栏 | 截图中无，可延后添加 |

## 技术约束

- Vue 3 + TypeScript + `<script setup lang="ts">`
- ECharts 5.x 负责所有地理可视化
- Naive UI 负责弹窗、下拉、输入框等交互组件
- Panda CSS 处理静态结构样式
- 内联 `:style` 处理动态颜色/尺寸
- Scoped CSS 仅用于 `@keyframes` 动画
- 模拟数据文件统一放在 `src/views/dashboard/mock/` 下
