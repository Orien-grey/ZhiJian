# 航行情报动态信息看板

面向航空公司运行控制中心（AOC）的情报监控工具，实时展示机场限制、航班动态和空域态势。

---

## 界面概览

页面采用三栏战术指挥布局，中间为中国地图，两侧为浮动覆盖面板：

```
┌──────────┬──────────────────────────────┬───────────┐
│ 左侧面板  │         核心地图               │ 右侧面板  │
│          │                              │          │
│ 告警时间轴│   ECharts 中国地图             │ 航班动态  │
│ 筛选器   │   航路 · 限制区 · 机场标记      │ 搜索筛选  │
│ 时间表格  │   + 五层悬停情报浮窗            │ 航班列表  │
│ 图层控制  │                              │ 标星置顶  │
└──────────┴──────────────────────────────┴───────────┘
```

**核心操作**：点击任意机场/限制条/航班项 → 弹出详情覆盖层 → 点 ✕ 关闭。

---

## 左侧面板：机场限制信息

**告警时间轴**（88px 高）——横向滚动卡片，红色="告"紧急告警，蓝色=普通通知。每 30 秒随机产生新告警，去重上限 30 条。纯展示不点击。

**筛选区**——按 ICAO 四字码或限制类型（8 种）过滤下方表格。

**时间表格**——甘特图式机场限制一览。横轴 06:00~次日 08:00，每格 30 分钟。颜色编码：
- 红色条：机场关闭 / 不可着陆 / 不可备降
- 紫色条：跑道关闭 / 滑行道关闭
- 绿色条：跑道不可起飞

行高 48px 紧凑排列，点击机场行弹出详情面板。

**图层控制**——一行紧凑 chip 标签（禁航通告 / 限制区 / 航路点 / 航路 / 运行机场），点击切换地图图层显隐。

## 中间地图

基于 ECharts 的中国及周边空域态势图：

- 22 条航路（贝塞尔曲线 + 流动光点动画）
- 5 条 FIR 空域边界虚线
- 7 个圆形限制区（雷达同心环效果）
- 6 个多边形禁航区（红色虚线 + 顶点光晕）
- 19 个机场 ICAO 标记（青色光点，可点击）

顶部悬浮 3 张统计卡：区域告警数、24 小时处理量、7 国国际统计。

"今日/明日/两日"按钮切换时间维度，地图限制区颜色和统计数值联动变化。

### 悬停情报浮窗

地图任意元素悬停弹出战术情报卡片（Teleport to body + 毛玻璃深色背景）：

| 悬停目标 | 浮窗信息 |
|---------|---------|
| **航路点** | 五字码 + 类型/频率 + 坐标 + 标高 + 管制扇区 + 所属航路 + 备注 |
| **航路** | 航线编号 + 方向/长度 + 航段列表 + 高度范围 + 管制单位 + 日均流量 + RNAV |
| **圆形限制区** | 名称 + 半径 + NOTAM编号 + 生效时间 + 高度 + 活动类型 + 管制/频率 + 详情 |
| **多边形禁航区** | 名称 + NOTAM + 生效时间 + 高度 + 活动类型 + 管制/频率 + 影响航路 + 详情 |
| **机场** | ICAO/IATA + 跑道数/最长 + 标高 + 运行时间 + 消防等级 + METAR + NOTAM |

## 右侧面板：航班动态

50 条航班，真实航班号/注册号，支持按航班号/机号/机场搜索、按状态筛选、全部/受影响航班切换。

黄色底=受影响航班（初始标注 5 条），★ 收藏自动置顶排序。点击航班 → 弹出航班分析面板。

---

## 弹出覆盖层

### 机场详情（点击限制条/机场行/地图机场）

5 个标签页：
- **机场信息**：消防等级、运行时间、磁差、燃油、跑道规格表
- **滑行信息**：SVG 机场平面图（所有机场共用示例），悬停滑行道查看 NOTAM
- **跑道信息**：物理规格网格（长/宽/道面/PCN/ILS/灯光/用途）+ 起飞着陆最低标准分方向展示
- **NOTAM 记录**：该机场历史通告列表（55 条覆盖 22 个机场）
- **设施气象**：通信频率、ILS/VOR/NDB 配置、实时 METAR/TAF

### 航班分析（点击航班项）

- 红色延误预警横幅 + 脉冲动画
- 可拖拽飞行时间轴（蓝色计划条 + 黄色延误条 + 航路点标记）
- SVG 高度剖面图（蓝色飞行曲线 + 红色虚线禁航区）
- 备选航线列表（可勾选对比）
- 延误因子分解 + 燃油计算 + 机组提示

## 技术栈

- **框架**：Vue 3 + TypeScript（Composition API + `<script setup>`）
- **地图**：ECharts 5.x（geo 坐标系 + 自定义 series）
- **图表**：纯 SVG 手绘（高度剖面图）
- **样式**：Scoped CSS + CSS Variables + 毛玻璃 backdrop-filter
- **弹窗**：Teleport to body（浮窗 + 限制区弹窗）
- **组件**：26 个在用 + 7 个旧组件保留不删
- **旧组件**（AlertMapView / AlertTimeline / LiveAlertFeed / PulseIndicator / SeverityRing / StatsStrip / ThreatRadar）保留在 components/dashboard/ 下，不导入不使用，不影响构建和运行。保留原因是这些组件曾参与过主组件树的引用，直接删除可能触发 HMR 链式失效导致白屏；分离干净后可直接复用或彻底清理。
