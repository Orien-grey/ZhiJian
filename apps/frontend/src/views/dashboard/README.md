# 航行情报动态信息看板

## 定位

面向**航空情报员 / 运行控制中心（OCC）** 的实时态势感知面板。聚合全国机场 NOTAM 航行通告、AI 解析结果、威胁评估与系统健康指标，一屏掌握空域情报全貌。

## 设计理念：Aero Command Center（航空指挥中心）

### 1. 暗黑基调 — 减少视觉疲劳，突出信息层级

运控中心通常处于暗光环境，白色界面刺眼且长时间注视易疲劳。全板采用 **深空蓝黑底（#060b1a）** 配合 **霓虹青色（#00d4ff）数据线**，模拟航空仪表盘 / 雷达屏幕的视觉语言：

- 背景叠加 48px 网格纹理 + 径向柔光，模仿雷达示波器质感
- 告警色（红 / 琥珀 / 蓝）仅在需要关注的数据上出现，避免色彩滥用
- 数值使用 `IBM Plex Mono` 等宽字体，强调数据的精确性和可读性

### 2. 信息密度分层 — 从上到下，从宏观到微观

| 层 | 组件 | 职能 |
|---|---|---|
| 概览层 | StatsStrip（6 卡片） | 核心 KPI：总告警量、活跃 NOTAM、受影响机场、风险等级、解析率、系统可用率 |
| 态势层 | AlertMapView + ThreatRadar + SeverityRing | 地理空间分布 + 威胁雷达扫描 + 等级占比 |
| 明细层 | LiveAlertFeed + AlertTimeline | 单条告警流 + 24H 趋势 |
| 底座层 | SystemStatusBar | 6 个子系统运行状态 |

用户视觉动线为 **Z 字形**：左上角标题 → 右扫统计卡 → 左下地图 → 右扫雷达/环形图 → 底部时间流。

### 3. 实时感 — 让数据"活"起来

- **PulseIndicator**：绿色呼吸灯 + "LIVE" 标签，持续传达"系统在线"信号
- **实时告警流**：每 8-15 秒自动推送新 NOTAM，带 "NEW" 高亮标记，3 秒后渐隐
- **威胁雷达**：3 秒一圈扫描旋转 + 目标点脉冲动画，模拟军用/航空雷达
- **航线图**：20 条贝塞尔弧线 + 流动光点，暗示航班持续运行
- **系统时钟**：秒级更新，强化实时感

### 4. 专业领域语义

所有模拟数据使用真实航空情报术语：

- **机场标识**：ICAO 四字码（ZBAA、ZSSS、ZGGG 等）+ 中文名称
- **NOTAM 类型**：跑道关闭、ILS 故障、军事活动空域限制、鸟击预警、火山灰漂移、GPS 干扰……
- **影响航路**：中国空域真实航路代号（G212、B215、A461、A593 等）
- **地区分区**：华北、华东、华南、西南、西北、华中、东北——对应中国空域管理情报区（FIR）

## 技术架构

```
AeroIntelDashboard.vue              ← 主页面（page-shell + SideNav 布局）
├── StatsStrip.vue                  ← 6 张 KPI 卡片（玻璃拟态 + 动态 accent 色）
├── AlertMapView.vue                ← ECharts 中国地图 + 航线轨迹 + 告警涟漪
├── ThreatRadar.vue                 ← SVG 雷达扫描 + 目标点 + 指标面板
├── SeverityRing.vue                ← ECharts 渐变 doughnut + 中心装饰环
├── LiveAlertFeed.vue               ← 实时告警滚屏列表 + 严重度筛选
├── AlertTimeline.vue               ← 24H 柱状图 + 趋势线
└── PulseIndicator.vue              ← 通用呼吸灯组件
```

### 设计模式约束

- **Panda CSS（静态结构）**：布局、间距、字体、过渡动画等不随数据变化的部分
- **内联 `:style`（动态颜色）**：accent 色、发光阴影等依赖数据的部分（绕过 Panda 构建时提取限制）
- **Scoped CSS（关键帧动画）**：`@keyframes` 定义，如雷达旋转、脉冲呼吸、扫描线移动

## 模拟数据说明

- **20 条静态告警**：覆盖 20+ 个中国机场，含紧急/预警/信息三个等级
- **实时流生成器**（`alertStreamGenerator`）：Generator 函数，模拟 6 种典型 NOTAM 的持续推送
- **24H 趋势**（`generateHourlyTrend`）：随机生成 + 人为加入早晚高峰特征
- **系统指标**：6 个子系统，其中一个故意设为"降级"状态以反映生产真实

## 页面路由

- 路径：`/dashboard`
- 导航标签：「情报看板」
- 位于 SideNav 第二项（总览 → 情报看板 → NOTAM 中心 → ...）
