# 航行情报动态信息看板

面向航空公司运行控制中心（AOC）的情报监控工具，实时展示机场限制、航班动态和空域态势。

---

## 界面概览

页面采用三栏战术指挥布局，中间为中国地图，两侧为数据面板：

```
┌──────────┬──────────────────────────────┬───────────┐
│ 左侧面板  │         核心地图               │ 右侧面板  │
│          │                              │          │
│ 机场限制  │   ECharts 中国地图             │ 航班动态  │
│ 告警时间轴│   航路 · 限制区 · 机场标记      │ 搜索筛选  │
│ 筛选器   │                              │ 航班列表  │
│ 时间表格  │                              │ 收藏关注  │
│ 图层开关  │                              │          │
└──────────┴──────────────────────────────┴───────────┘
```

**核心操作**：点击任意机场/限制条/航班项 → 中间弹出详情面板 → 点 ✕ 关闭。

---

## 左侧面板：机场限制信息

**告警时间轴**（第二层）——横向滚动卡片，红色="告"紧急告警，蓝色=普通通知。"NEW"标记每 10 秒自动产生。

**筛选区**（第三层）——按 ICAO 四字码或限制类型（8 种）过滤下方表格。

**时间表格**（第四层）——甘特图式机场限制一览。横轴 06:00~次日 08:00，每格 30 分钟，右侧滚动查看次日凌晨时段。颜色编码：
- 红色条：机场关闭 / 不可着陆 / 不可备降
- 黄色条：跑道关闭 / 滑行道关闭
- 绿色条：跑道不可起飞

点击颜色条 → 弹出机场详情面板；点击机场行 → 地图定位该机场。

**图层开关**（第五层）——勾选/取消控制地图上对应内容的显隐。

---

## 中间地图

基于 ECharts 的中国及周边空域态势图：

- 航路（贝塞尔曲线 + 流动光点动画）
- FIR 空域边界虚线
- 圆形限制区（雷达同心环效果）
- 多边形禁航区（红色虚线 + 顶点光晕）
- 机场 ICAO 标记（白点，可点击）

顶部悬浮 3 张统计卡：区域告警数、24 小时处理量、7 国国际统计。

"今日/明日/两日"按钮切换时间维度，地图限制区颜色和统计数值联动变化。

---

## 右侧面板：航班动态

50 条航班，支持按航班号/机号/机场搜索、按状态筛选、全部/受影响航班切换。

黄色底=受影响航班，红色标签=公司航线，★ 可收藏切换。点击航班 → 弹出航班分析面板。

---

## 弹出面板

### 机场详情（点击限制条/告警卡片/地图机场）

5 个标签页：
- **机场信息**：消防等级、运行时间、磁差、燃油、跑道规格表
- **滑行信息**：SVG 机场平面图，悬停滑行道查看 NOTAM 原文
- **跑道信息**：起飞/着陆最低标准，异常值红高亮
- **NOTAM 记录**：该机场历史通告列表（55 条覆盖 19 个机场）
- **设施气象**：通信频率、ILS/VOR/NDB 配置、实时 METAR/TAF

### 航班分析（点击航班项）

受影响航班弹出：
- 红色延误预警横幅
- 可拖拽飞行时间轴（蓝色计划条 + 黄色延误条 + 航路点标记）
- SVG 高度剖面图（蓝色飞行曲线 + 红色虚线禁航区）
- 备选航线列表（可勾选对比）
- 延误因子分解 + 燃油计算 + 机组提示

## 数据来源

全部为模拟数据（7 个 mock 文件），覆盖：
- 24 个机场限制 + 48 条告警
- 18 个机场详情（Wikipedia/CAAC AIP 真实数据）
- 50 条航班动态 + 14 条分析数据
- 47 个航路点 + 21 条航路 + 12 个限制区
- 55 条 NOTAM 历史记录 + 5 个机场气象
